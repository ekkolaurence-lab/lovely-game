Lovely - Long Distance Couple Game (Spicy & LDR Edition)

A real-time, interactive web game designed for long-distance couples to connect, play side-by-side games, reveal spicy secrets, and fulfill remote video dares.

✨ Features

🔄 Real-Time Synchronization: Live room synchronization powered by Firebase Firestore. Actions taken by one player immediately update on the partner's screen.

🎮 4 Game Modes:

This or That: Pick preferences side-by-side and see live match indicators.

Would You Rather: Fun scenario dilemmas calibrated for couples.

Truth or Dare: Playful truths and spicy remote dares.

🔥 Secret Vault: Locked secret prompts with a "Pass & Face Penalty" mechanic.

🌶️ Heat Level Filter: Toggle dynamically between Mild, Warm, Spicy, and Extra.

➕ Custom Secret Prompts: Add your own custom secrets and penalties live during gameplay.

📱 Mobile & Desktop Responsive: Beautiful UI styled with Tailwind CSS, inspired by modern couple apps.

🚀 Quick Setup Guide

1. Save locally on your PC

Create a folder named lovely-game on your Desktop or Documents.

Save the game code inside that folder as index.html.

2. Host and Share Online

Option A: Netlify Drop (Fastest - 1 Minute)

Go to Netlify Drop.

Drag and drop your lovely-game folder onto the page.

Netlify will generate a free public link (e.g. https://lovely-couple-game.netlify.app).

Send the link to your partner!

Option B: GitHub Pages

Create a repository on GitHub named lovely-game.

Upload index.html.

Go to Settings → Pages → select main branch → Save.

🎲 How to Play Together

Both you and your partner open the live website link on your phone or PC.

Host: Enter your nickname and click Create New Room. You will receive a 4-letter Room Code.

Guest: Enter your nickname, type the Room Code, and click Join.

Jump on a video or phone call together and start playing!
